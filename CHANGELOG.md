# Changelog

All notable changes to this project will be documented in this file.

## [0.54.0] - 2025-08-26

### Documentation

-   **Project Overview:** Added a high-level description of the project, its vision, and goals.
-   **Architecture:** Introduced detailed documentation for both the Go backend and the Flutter frontend, including diagrams and component breakdowns.
-   **API Reference:** Created a comprehensive guide for the Socket.IO-based API, detailing all events and data structures.
-   **Database Design:** Outlined the current in-memory data storage and the planned relational database schema.
-   **Deployment Guide:** Provided instructions for deploying the application to various environments, including Docker and cloud platforms.
-   **Development Setup:** Added a step-by-step guide for setting up a local development environment.
-   **Testing Strategy:** Documented the project's testing philosophy, tools, and procedures for both backend and frontend.
-   **README:** Added a main README for the documentation folder to provide a clear entry point.

### Miscellaneous

-   Updated `.gitignore` to exclude `.claude-cli/` directory.
